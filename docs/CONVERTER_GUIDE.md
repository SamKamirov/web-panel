# Руководство по использованию скрипта конвертации

## Установка

1. Установите зависимости если вы их ещё не установили

```bash
npm i
```

Done!
Теперь вы можете конвертировать ваши файлы.

2. Глобализация\* (credit for the name goes to `zevordex`)

Вы можете сделать скрипт глобально доступным из любой точки системы.

Для этого:

- Выдайте конвертеру необходимые права

```bash
sudo chmod +x ./web-convert.js
```

- Создайте ссылку на файл

```bash
sudo ln -s ~/path/to/web-panel/source/web-convert.js /usr/local/bin/web-convert
```

Done! Теперь вы можете вызывать данный скрипт конвертации из любой точки системы. Просто запустите его

```bash
web-convert
```

\* \- необязательно

\* - если вы не выполнили шаг с глобализацией, вызов скрипта производится так:

```bash
node path/to/web-panel/source/web-convert.js
```

## Использование

Скрипт конвертации автоматически сканирует директорию, в которой был запущен, на предмет наличия файлов, в названии которых присутствует строка `ADocumentJournal`.

Данное поведение вы можете изменить в файле `web-convert.js`, изменив конфигурацию.

```js
const FILE_SUBSTRING = "ADocumentJournal";
```

Путь сохранения преобразованых файлов по умолчанию - директория `public/data`

```
web-panel/
	|---public/
	|		|---data/
	|---smth-else
```

Данное поведение вы можете изменить в файле `web-convert.js`, изменив конфигурацию.

```js
const SAVE_PATH = `${__dirname}/../public/data/data.json`;
```

### Сценарии

Для получения информации по использованию скрипта, вызовите его командой

```bash
web-convert --help
```

## Синхронизатор

Конфигурация синхранизатора находится в `source/config`

Для указания удалённого сервера, измените переменную `REMOTE`.

Для указания ключа для доступа к серверу, измените переменную `SHELL`
